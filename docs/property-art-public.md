# 공공·금융 장소 일러스트 제작 기록

2026-11-22. Built-in `image_gen.imagegen`을 사용했다. CLI/API fallback은 사용하지 않았다. 4개 장소의 봄 원본을 각각 별도 생성하고, 각 장소의 봄 원본만 edit target으로 사용해 여름·가을·겨울을 만들었다. 다른 장소의 구조나 가구를 재사용하지 않았다.

스타일은 `dist/assets/scene-office-spring.png`를 `view_image`로 확인한 뒤 프롬프트에 반영했다. 봄 생성 호출에는 참조 이미지를 첨부하지 않았으며, 기존 사무실 이미지는 구도/가구 참조로 사용하지 않았다. 모든 호출의 `transparent_background`는 `false`였다.

최종 16개 파일은 `dist/assets`에 복사했다. 모두 PNG 1672 × 941이며, 파일 검증과 SHA-256 고유성 검사에 통과했다. 16개 모두 육안 검수하여 사람·동물·텍스트·로고가 없고, 각 장소 내 카메라/가구 배치가 계절 간 유지됨을 확인했다. 봄 벚꽃·새잎, 여름 녹음, 가을 단풍, 겨울 눈·앙상한 가지가 창밖에서 구별된다. 코드 수정, 커밋, 배포는 수행하지 않았다.

## 계절 편집 최종 프롬프트

아래 프롬프트는 각 계절에서 4개 장소에 동일하게 사용했다. `referenced_image_paths`에는 위 표의 해당 장소 봄 생성 원본 경로 하나만 전달했다. 다른 계절의 출력을 연쇄 편집하지 않았다.

### summer

```text
Use case: lighting-weather. Asset type: seasonal variant of a Korean visual novel game background. Input image 1 is the EDIT TARGET and the sole composition reference. Make a strictly controlled seasonal edit of this exact image. Preserve the identical 16:9 framing, camera, perspective, architecture, window shapes, all indoor furniture positions, exact furniture shapes and proportions, surfaces, indoor plants, paper objects, blank screens, wall décor, and all indoor details. Preserve the same crisp thin blue-gray outlines, restrained flat colors, gentle cel shadows, anime background finish. The edit must look like the same room photographed from the exact same fixed camera in another season, NOT a redesign. Change only the exterior seasonal vegetation/weather visible through windows and a very subtle appropriate daylight tint. NO people, animals, text, words, numbers, logos, watermarks, or UI. Keep clear character-compositing foreground space identical. Seasonal change required: SUMMER, May–August. In all visible exterior window areas replace every pink cherry blossom and spring foliage with mature lush deep green summer tree canopies. No pink flowers or autumn foliage. Clear bright blue summer daytime sky. Ground and buildings remain in exactly the same positions. Keep all interior lighting largely unchanged with only the subtle summer daylight tint necessary.
```
